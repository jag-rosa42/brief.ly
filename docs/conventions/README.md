# Development Conventions

## Purpose

This directory contains the development conventions followed throughout the
Transcendence project.

It defines the team's workflows, coding practices, and day-to-day development
rules.

---

## Documentation Map

| Document | Purpose |
|----------|---------|
| `commits.md` | Commit message convention |
| `git-conventions.md` | Branching strategy, branch naming, and Git rules |
| `git-workflow.md` | Daily Git workflow and common Git operations |

---

Unlike ADRs, which explain **why** architectural decisions were made, these
documents describe **how** contributors are expected to work within the project.
