# [S-01] Fetch Content from External Sources

As the system, I want to discover and extract articles from configured external
sources when requested so that structured content is available for processing.

## Technical Tasks

### Backend — Content Service

- [x] Discover article URLs from newsAPI
  - which is free in local but 450$/month for production💲💲💲
  - which is limited to 100 request/day
- [x] Extract article content and metada using Newspaper3k.
- [x] Persist extracted articles with their source and external identity.
- [x] Store title, content, authors, URL, image, publication date and fetch date.
- [x] Ensure failure of one source does not block the service.
- [x] Log synchronization results and failures.

## Tests

- [x] Content is fetched and persisted correctly.
- [x] Source information is recorded.
- [x] Failure of one source does not affect others.

## Acceptance Criteria

- [x] Discovered articles are extracted and persisted.
- [x] Every article retains its source and external identity.
- [x] The same external article is not inserted twice for one source.
- [x] Synchronization failures are logged.

## Out of scope

- [ ] Semantic normalization beyond Newspaper3k extraction.
- [ ] Duplicate detection across different sources.
- [ ] Classification and topic assignment.
- [ ] Periodic execution, source intervals, and synchronization timestamps.
